01 / PROJECT OVERVIEW

What is it?

Paw Prints Weekly is a school-publication website designed around student stories, school news, and a clear editorial identity. The experience brings together different content categories while keeping the publication’s name and mascot recognizable.

The public homepage emphasizes storytelling and makes the reader journey visible from the first screen.

02 / THE CHALLENGE

The problem to solve

An editorial website serves two audiences: readers discovering stories and contributors navigating a publishing workflow. Readers need obvious routes into recent and topic-specific content.

It also needs to feel like a publication rather than a generic dashboard or a plain feed of links.

03 / APPROACH

Designing the solution

The public interface establishes a strong masthead, readable typography, school-specific identity, and navigation for news, student life, sports, perspectives, and more.

A staff portal entry is visible in the published navigation. This portfolio does not claim any private editorial tools or moderation features have been independently tested.

04 / KEY CAPABILITIES

05 / IMPLEMENTATION

Behind the build

The publicly visible site uses multiple dedicated style layers, page components, and interaction scripts. Its homepage organizes readers around the publication identity before asking them to choose a topic.

The screenshot depicts the public-facing page. It does not expose private student records, contributor credentials, or unpublished submissions.
