01 / PROJECT OVERVIEW

What is it?

Wtv Innovations is a studio website connecting different creative and technical projects under a shared identity. Its public homepage links directly to game experiences and dedicated pages for products and the studio’s story.

It provides a useful organizing layer for an otherwise wide range of projects.

02 / THE CHALLENGE

The problem to solve

A collection of projects can be difficult to navigate when each has a different audience, visual language, and stage of development.

The studio site needs to communicate what connects them without blurring the distinction between games, products, and external client-facing work.

03 / APPROACH

Designing the solution

The public site uses distinct Games, Digital Products, and Our Story destinations, plus direct routes into ProfitLands and NationWars.

Simple navigation and cross-project links make it easier for people to understand the broader product ecosystem.

04 / KEY CAPABILITIES

What the project includes

05 / IMPLEMENTATION

Behind the build

The source site is in the WtvStudios repository while its public brand is Wtv Innovations. Keeping the existing repository path preserves current public links.

The studio site can serve as a high-level directory; the personal portfolio complements it with individual case studies and a development-focused perspective.
